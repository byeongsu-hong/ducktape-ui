# Welcome to your notes

Everything you write here is saved as a plain Markdown file in your notes folder, a moment after you stop typing. No save button, no dialogs.

## Writing

Markdown stays out of the way until the caret enters a formatted span: **bold**, *emphasis*, `code`, and [links](https://iced.rs) all render inline.

- Lists continue when you press Enter
- Tab nests an item, Shift+Tab lifts it back out
- Numbered lists renumber themselves

## Shortcuts

- Command/Ctrl+N — new note
- Command/Ctrl+F — find in this note
- Command/Ctrl+B, I, ` and K — bold, italic, code, link
- Command/Ctrl+Z and Shift+Z — undo and redo
