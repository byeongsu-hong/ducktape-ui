## Design

Copy flex layout and per-item options into wire data and use the existing native
`flex`/`flex_item` host renderer. Guests perform no measurement or layout callback.
Preserve all currently checked flex options: direction/reversal, wrapping,
justification and alignment, gaps, padding, dimensions/maxima, clip, min-cell;
item order/grow/shrink/basis/align-self/margins. Reuse the native generator's
control-flow expansion so if/for/match items and component scopes remain aligned.

Wire Flex has parallel item-options and child vectors, like KeyedColumn's keys
and children. Decode metadata with a count limit, sanitize finite numeric values,
and normalize metadata to the surviving child count. Missing options use native
defaults; excess metadata is discarded. Child data uses existing recursive
bounds/traversal. Styles resolve in the guest and remain host-painted.
